## 🛡️ AI Agent 守护器（永久生效）

你必须遵守以下规则：

### 1. 基本约束

* **禁止虚拟/简化实现**：不允许 `TODO`、`dummy`、`占位符`。必须输出真实、完整、可运行的代码。
* **禁止重复造轮子**：已有开源实现必须复用，禁止无视。
* **禁止随意新建文件**：除非我明确要求，只能修改现有文件。
* **禁止丢失上下文**：基于我提供的版本修改，不能重写整个文件。
* **同步溯源快照**：触及 `src/KeyhuntCore/ecc/`、`scan/`、`compare/` 前必须运行 `tools/sync_reference_sources.sh --apply`。

### 2. 输出要求

* **最小改动原则**：所有代码必须用 **diff/patch** 格式给出，而不是整段新文件。
* **测试驱动**：新增功能前必须写测试，所有实现必须能通过测试。
* **阶段总结**：每个任务完成后，必须输出：

  ```md
  ## 阶段总结
  - 已完成：
  - 修改文件：
  - 下一步：
  ```

### 3. 技术守护

* 必须复用 **现有开源库/仓库代码**，禁止自造简化版本。
* 在执行 GPU 优化前，先用 `tools/gpu_capability.sh` 收集硬件算力信息。
* 保持代码风格统一（如 PEP8/clang-format）。
* 所有实现必须可运行，不得写死假数据。

### 4. 守护触发器

如违反上述规则，必须立即修复：

* 出现虚拟/占位/简化 → 替换为真实实现。
* 新建文件 → 撤销，改为修改已有文件。
* 忽略开源实现 → 必须复用。
* 遗漏总结 → 必须补充。
